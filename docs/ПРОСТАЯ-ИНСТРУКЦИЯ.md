# Установка и использование transcribe-media

## Установка из чата

1. Распакуйте архив в отдельную папку.
2. Откройте папку как локальный проект Codex или рабочую папку Claude Code.
3. Попросите ассистента установить и настроить скилл:

   ```text
   Установи transcribe-media из этой папки и настрой его. Сначала прочитай инструкцию по установке.
   ```

До регистрации скилла ассистент прочитает `УСТАНОВИТЬ-ИЗ-ЧАТА.md` и проведёт установку по шагам. Он покажет, что будет проверять и устанавливать, и запросит согласие перед каждым действием, которое его требует. Для первого запуска без Node предусмотрен native bootstrap из чата. Если клиент не может запускать локальные программы, используйте терминальный способ ниже.

В панели видны этапы и состояние работы. Вопросы задаются в чате, сама панель показывает состояние и измеренный прогресс, если его можно рассчитать. Закрытие вкладки не останавливает установщик.

## Установка через терминал

Сначала распакуйте архив в отдельную папку. На Windows дважды щёлкните `Установить.cmd` либо выполните в PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\Tools\transcribe-media\start.ps1"
```

Замените пример пути на путь к распакованной папке. На macOS или Linux выполните:

```sh
sh "/полный/путь/transcribe-media/start.sh"
```

Мастер задаёт вопросы в терминале и показывает состояние в локальной панели. Если Node нужно установить, он сначала покажет план и попросит согласие. Глобальный PATH при установке приватного Node не меняется.

## Подключение сервиса и настройки

После установки мастер сам открывает в браузере страницу настроек. На ней карточки Deepgram и AssemblyAI: ссылки на регистрацию и создание ключа, поле для ключа и кнопка «Сохранить и проверить». Кнопка отправляет сервису один бесплатный проверочный запрос без аудио; ключ, который сервис не принял, не сохраняется. Подключение можно отложить. Вводите ключ только на этой странице; не отправляйте его в чат.

На той же странице — настройки расшифровки. По умолчанию язык определяется автоматически, длина блока субтитров — 30 секунд, форматы `txt`, `srt`, `vtt`, разделение участников выключено. Их можно поменять на странице или попросить ассистента в чате.

После установки откройте новый чат в выбранном клиенте и передайте локальный файл или ссылку. Например:

```text
Расшифруй файл «D:\Видео\интервью.mp4». Сохрани текст и субтитры.
```

```text
Получи текст видео по этой ссылке: [вставьте ссылку]. Сохрани текст и субтитры.
```

Перед возможной платной отправкой аудио в Deepgram или AssemblyAI ассистент должен показать способ обработки и запросить отдельное согласие. Доступ к ролику зависит от сайта; cookies не используются без отдельного разрешения. Если компьютер выходит в интернет через прокси или VPN, YouTube может принять запрос за автоматический — тогда скажите ассистенту «читай ссылки напрямую» (настройка `--source-proxy direct`).

Полная справка ручного CLI находится в [skills/transcribe-media/references/usage.md](../skills/transcribe-media/references/usage.md). Фактические ограничения и непроверенные сценарии перечислены в [limitations.md](limitations.md).

### Если понадобится поменять ключ или настройки

В локальном чате скажите: «Открой настройки транскрибации» или наберите команду `/transcribe-settings` (в Codex — `$transcribe-settings`). Ассистент откроет ту же страницу и даст ссылку. Язык, длину субтитра и форматы можно поменять и просто просьбой в чате, без страницы.

Ключ относится к пользователю ОС, в том числе при установке для `project`. Если сервис недоступен в момент проверки, ключ сохранится со статусом «не проверен» — проверьте его позже кнопкой «Проверить снова». Из терминала ключ можно ввести скрыто командой `node "<путь-к-пакету>/skills/transcribe-media/scripts/installer.mjs" connect`.
