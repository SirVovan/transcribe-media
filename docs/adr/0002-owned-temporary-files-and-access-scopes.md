# ADR-0002: Владение временными файлами и области доступа

## Контекст

Обработка использует временные файлы, ключи провайдеров и, при отдельном разрешении, cookies источника. Очистка не должна затрагивать пользовательские файлы, а доступы не должны утекать через неожиданные пути или перенаправления.

## Решение

Каждый запуск владеет отдельным temp-каталогом и явным списком созданных файлов. Удаление ограничивается этим каталогом после проверки реального пути и ссылок. Исходники, результаты, ключи, кэш и записи запросов вне области temp не принадлежат очистке. Cookies читаются только при явном разрешении и не передаются API распознавания; заголовки доступа не переносятся на другой origin.

## Почему

Альтернатива — удалять файлы по шаблону или считать каталог достаточной границей. Ссылки и уже существующие файлы могут вывести такую операцию за пределы ресурсов запуска; автоматическая передача заголовков при перенаправлении расширяет область доступа.

## Последствия

Очистка требует проверяемого происхождения каждого кандидата и при сомнении оставляет файл. Доступы к источникам, провайдерам и локальным файлам остаются раздельными по цели и явному разрешению.
