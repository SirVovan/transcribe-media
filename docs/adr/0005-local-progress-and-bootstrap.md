# ADR 0005: Локальный прогресс и headless bootstrap

## Контекст

Пользователь должен видеть ход установки в панели и запускать мастер из чата даже на машине без Node.js. Панель не должна зависеть от сборки или внешних ресурсов, а bootstrap — от глобального PATH.

## Решение

Панель — локальные HTML/CSS/JS без CDN, обслуживаемые на loopback и показывающие безопасный снимок общего engine. Прогресс отражает только измеренные события: при неизвестном общем размере показываются байты или состояние операции без процента. Нативные `start.ps1` и `start.sh` поддерживают headless `--chat`: `--plan` показывает план bootstrap без бинарников и сети; `--allow-check` проверяет Node после согласия; `--allow-node-install` после согласия устанавливает приватный Node и запускает `serve`. Вывод содержит фактическую команду с путём Node для продолжения.

## Почему

Общий engine даёт панели и терминалу одинаковое состояние. Локальные ресурсы и loopback ограничивают поверхность панели. Измеримые события не создают ложное впечатление точности. Headless путь позволяет чату управлять запуском без необходимости отвечать на терминальные вопросы.

## Последствия

Закрытие вкладки не останавливает мастер; повторное открытие получает актуальный снимок. Bootstrap проверяет SHA-256 Node и не меняет глобальный PATH. Интерактивный Node bootstrap для чата отклонён: без локального ответчика вопросы зависли бы, поэтому режим чата принимает явные флаги согласия и возвращает план или запускает сервис. Проценты по таймеру отклонены, поскольку они не отражают реальный ход операции.
