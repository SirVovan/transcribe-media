# ADR-0003: Сохранение исходного ответа до нормализации

## Контекст

Ответ провайдера может содержать данные, которые преобразуются во внутреннюю схему транскрипта. Некорректные тайминги или ошибка преобразования не отменяют факт уже выполненного платного запроса.

## Решение

Сохранять успешный ответ провайдера без изменений до нормализации. Исходный ответ и нормализованный транскрипт — отдельные представления. Неизвестные поля, включая модель, не додумывать; запрошенную модель хранить среди параметров запроса.

## Почему

Альтернатива — сначала нормализовать и сохранять только внутренний формат. При ошибке нормализации исходные данные оплаченного ответа могут быть потеряны, а восстановление результата потребует новой отправки.

## Последствия

Сохранённый ответ можно повторно обработать локально и восстановить результат без нового запроса. Формат ответа провайдера остаётся исходным свидетельством; качество и точность нормализованных таймингов оцениваются отдельно.
