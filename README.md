# transcribe-media

Скилл для Claude Code и Codex: расшифровывает локальные аудио- и видеофайлы, а также доступные ссылки YouTube, TikTok и Instagram Reels. Сначала ищет готовые субтитры и кэш, а распознавание отправляет в Deepgram или AssemblyAI только с вашего согласия. Результат — текст и субтитры (TXT, SRT, VTT).

Проверено на Windows. На macOS и Linux не проверялось.

## Установка

Нужен Claude Code или Codex на компьютере (приложение, CLI или расширение редактора). Браузерный чат без доступа к компьютеру установить скилл не сможет.

### Проще всего: попросите ассистента

Откройте любую локальную папку в Claude Code или Codex и напишите:

```text
Прочитай README репозитория https://github.com/SirVovan/transcribe-media и установи скилл transcribe-media по разделу «Для ИИ-ассистента»: скачай архив репозитория и запусти мастер установки.
```

Ассистент скачает пакет, запустит мастер установки и проведёт по шагам: проверит программы (Node.js, FFmpeg, yt-dlp), после вашего согласия поставит недостающие, откроет страницу настроек для ключа сервиса распознавания. Вопросы задаются в чате, ход установки виден на странице в браузере.

Если ассистент только скопировал папку скилла и на этом закончил (так делает встроенный установщик скиллов Codex), напишите следующим сообщением в том же чате «Настрой transcribe-media» — мастер поставит программы и второй скилл `transcribe-settings`.

### Claude Code: каталог плагинов

```text
/plugin marketplace add SirVovan/transcribe-media
/plugin install transcribe-media@transcribe-media
```

Затем в новом чате напишите «Настрой transcribe-media» — ассистент пройдёт первую настройку. Обновления приходят через `/plugin`.

### Codex и другие ассистенты: npx skills

Нужен Node.js 22 или новее.

```text
npx skills add SirVovan/transcribe-media -g -a codex
```

Отметьте оба скилла (`transcribe-media` и `transcribe-settings`). Затем в новом чате напишите «Настрой transcribe-media».

### Без чата (Windows)

Скачайте [архив](https://github.com/SirVovan/transcribe-media/archive/refs/heads/main.zip), распакуйте его в отдельную папку и дважды щёлкните `Установить.cmd`. Мастер задаёт вопросы в терминале. На macOS/Linux запустите `sh start.sh` из распакованной папки.

## Для ИИ-ассистента: установка по ссылке на этот репозиторий

Если пользователь просит установить скилл по ссылке на этот репозиторий, не используй встроенный установщик скиллов клиента (в Codex — `skill-installer`): он копирует одну папку и не ставит программы. Действуй так:

1. Скажи пользователю, что скачаешь архив репозитория с GitHub и куда. Git не нужен. В Codex выполняй команды вне песочницы: им нужна сеть и домашняя папка пользователя.

   Windows (PowerShell):

   ```powershell
   $ErrorActionPreference = 'Stop'
   $dir = Join-Path $env:LOCALAPPDATA 'transcribe-media-package'
   $zip = Join-Path $dir 'main.zip'
   New-Item -ItemType Directory -Force -Path $dir | Out-Null
   Remove-Item -Force -LiteralPath $zip -ErrorAction SilentlyContinue
   [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
   Invoke-WebRequest -UseBasicParsing -Uri 'https://github.com/SirVovan/transcribe-media/archive/refs/heads/main.zip' -OutFile $zip
   Expand-Archive -Force -LiteralPath $zip -DestinationPath $dir
   ```

   macOS/Linux:

   ```sh
   dir="$HOME/.local/share/transcribe-media-package"; mkdir -p "$dir"; rm -f "$dir/main.zip"
   curl -fsSL -o "$dir/main.zip" https://github.com/SirVovan/transcribe-media/archive/refs/heads/main.zip && unzip -oq "$dir/main.zip" -d "$dir"
   ```

   Корень пакета — папка `transcribe-media-main` внутри `$dir`.

   Если загрузка не удалась (например, «Невозможно соединиться с удаленным сервером» или ошибка прокси), не продолжай: старая распакованная копия может быть прежней версией. Частая причина — в системе указан прокси, который сейчас не отвечает. Не меняй и не отключай системные настройки прокси: они могут быть нужны пользователю. Скажи пользователю, что обычная загрузка не прошла, и спроси разрешения скачать архив напрямую, без прокси, только для этой загрузки. После согласия повтори те же команды, добавив первой строкой:

   - Windows: `if ($PSVersionTable.PSVersion.Major -ge 6) { $PSDefaultParameterValues['Invoke-WebRequest:NoProxy'] = $true } else { [Net.WebRequest]::DefaultWebProxy = $null }`
   - macOS/Linux: `export NO_PROXY='*' no_proxy='*'`

   Если не прошла и прямая загрузка, передай пользователю текст ошибки и предложи скачать [архив](https://github.com/SirVovan/transcribe-media/archive/refs/heads/main.zip) в браузере и распаковать его в `$dir`.

2. Прочитай `<корень-пакета>/skills/transcribe-media/references/install.md` и пройди установку по нему в режиме «Пакет». Все согласия из инструкции обязательны.

## Обновление

Напишите в Claude Code или Codex, в той же папке, где ставили скилл:

```text
Прочитай README репозитория https://github.com/SirVovan/transcribe-media и обнови скилл transcribe-media по разделу «Для ИИ-ассистента: обновление»: скачай свежий архив и запусти мастер с обновлением.
```

Настройки, ключи сервисов и готовые расшифровки сохраняются. После обновления откройте новый чат. Если скилл ставили через каталог плагинов Claude Code, обновляйте его через `/plugin`.

## Для ИИ-ассистента: обновление

Обновить скилл — значит поставить новую версию пакета поверх старой. Не правь файлы установленного скилла вручную и не переписывай его SKILL.md по этому README: программа скилла от этого не изменится, и старые ошибки останутся.

1. Найди установленную копию — папку `transcribe-media` с `SKILL.md` — и определи по её пути клиент и область:
   - `<проект>/.agents/skills/transcribe-media` — Codex, область «проект»;
   - `<домашняя папка>/.agents/skills/transcribe-media` — Codex, область «пользователь»;
   - `<проект>/.claude/skills/transcribe-media` или `<домашняя папка>/.claude/skills/transcribe-media` — Claude Code, «проект» или «пользователь».

   Если скилл поставлен через `/plugin install` (Claude Code), скажи пользователю обновить его через `/plugin` и на этом закончи. Если копий несколько, спроси, какие обновлять.
2. Скачай свежий архив командами из шага 1 раздела «Для ИИ-ассистента: установка по ссылке на этот репозиторий»: они перезаписывают прежнюю распакованную копию. В Codex выполняй команды вне песочницы.
3. Пройди `<корень-пакета>/skills/transcribe-media/references/install.md` в режиме «Пакет». На шаге выбора укажи клиент и область найденной копии (для области «проект» — тот же путь проекта). Мастер увидит установленный скилл: `plan` вернёт `awaiting: "update"`, в плане будет «Обновить скилл в …; настройки и результаты сохраняются». После согласия пользователя на план запусти `install` с `--update`.
4. Назови пользователю новую версию — поле `version` в `<корень-пакета>/.claude-plugin/plugin.json` — и попроси открыть новый чат: клиент подхватывает обновлённый скилл в новом чате.

## После установки

Попросите ассистента расшифровать файл или ссылку:

```text
Расшифруй файл «D:\Видео\интервью.mp4». Сохрани текст и субтитры.
```

Перед возможной платной отправкой аудио ассистент показывает способ обработки и параметры и спрашивает согласие. Доступность ролика по ссылке зависит от сайта и прав доступа.

## Подключить сервис распознавания

После установки мастер сам открывает в браузере страницу настроек. Позже её открывает просьба в чате («Открой настройки транскрибации») или команда `/transcribe-settings` (в плагине Claude Code — `/transcribe-media:transcribe-settings`, в Codex — `$transcribe-settings`). На странице — карточки Deepgram и AssemblyAI со ссылками на регистрацию и создание ключа, поле ключа и кнопка «Сохранить и проверить», а также настройки расшифровки. Кабинет сервиса вы открываете и проходите сами.

Кнопка «Сохранить и проверить» отправляет сервису один бесплатный проверочный запрос без аудио. Ключ, который сервис не принял, не сохраняется. Ключ вводите только на странице, не в чате. Он хранится в папке пользователя ОС. По умолчанию язык определяется автоматически, длина блока субтитров — 30 секунд.
