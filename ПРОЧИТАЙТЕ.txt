УСТАНОВКА TRANSCRIBE-MEDIA НА WINDOWS

1. Распакуйте весь ZIP-архив в любую обычную папку.
2. Откройте папку transcribe-media и дважды щёлкните Установить.cmd.
3. Следуйте мастеру. Ответы вводятся в открывшемся терминале;
   страница в браузере показывает ход установки.

Мастер предложит выбрать Codex или Claude Code и область установки,
проверит программы и установит недостающие после вашего согласия.
Сначала он ищет уже установленные Node.js, FFmpeg и yt-dlp. Недостающее
ставит через winget — так, как рекомендуют разработчики этих программ.
Для Node.js Windows может спросить разрешение на изменения: нажмите «Да».
Затем мастер предложит подключить сервис распознавания и сохранить
настройки. API-ключ вводите только в отдельной локальной форме, не в чате.
Подключение сервиса можно отложить.

Можно установить и из чата: откройте папку transcribe-media в Codex или
Claude Code и попросите установить скилл — ассистент прочитает
УСТАНОВИТЬ-ИЗ-ЧАТА.md и проведёт установку.

После завершения откройте новый чат в выбранном клиенте и попросите
расшифровать локальный файл или доступную ссылку через transcribe-media.
Клиент Codex или Claude Code должен быть установлен отдельно.
