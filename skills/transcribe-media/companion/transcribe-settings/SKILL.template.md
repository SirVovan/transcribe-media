# transcribe-settings

Открой страницу настроек скилла transcribe-media.

Этот скилл установлен рядом с основным: папка `transcribe-media` лежит в том же каталоге `skills`, что и папка этого скилла. Вычисли абсолютный путь к ней из текущего файла и выполни, не меняя cwd:

```
node "/абсолютный/путь/skills/transcribe-media/scripts/installer.mjs" settings
```

В Codex запускай эту команду сразу с запросом на выполнение вне песочницы: она читает файлы из домашней папки пользователя, пишет в `%LOCALAPPDATA%\transcribe-media`, запускает локальный сервер и открывает браузер. Ошибка `EPERM` или `EACCES` в песочнице не означает поломку установки: повтори команду вне песочницы.

Команда сама запускает локальный сервер в фоне (или находит уже работающий), открывает страницу в браузере и сразу возвращает JSON. Дай пользователю ссылку из поля `url` одной строкой и скажи, что ключ вводится на странице: кнопка «Сохранить и проверить» отправляет один бесплатный проверочный запрос без аудио.

Если пользователь вставил ключ в чат, не используй его, не повторяй и не сохраняй; попроси ввести его на странице.

Если папки `transcribe-media` рядом нет или команда вне песочницы завершилась ошибкой, перескажи безопасный текст ошибки и предложи установить или переустановить transcribe-media. Не запускай установку без просьбы.
